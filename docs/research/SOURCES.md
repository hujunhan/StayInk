# Sources

Register a source before citing it from another research file. Pin repository sources to a full commit SHA rather than a branch or tag.

## Source template

```markdown
## SRC-NNN — Short name

- Repository: <URL or UNKNOWN>
- Commit SHA: <full SHA or UNKNOWN>
- License: <license and evidence location, or UNKNOWN>
- Retrieved: <YYYY-MM-DD>
- Local reference path: <.research/repos/name or NOT CLONED>
- Scope: <what this source may establish>
- Notes: <limitations, provenance, or UNKNOWN>
```
